# SchemeSathi prototype

A self-contained responsive web prototype based on the AI-driven scheme matching concept. It contains a three-step entrepreneur profile flow, locally calculated scheme matches, scheme detail/checklist interactions, application progress, notifications, and responsive navigation.

## Run it

Open `index.html` in any modern browser. No installation, server, or internet connection is needed.

The prototype stores the entered profile only in the browser's local storage. Use your browser's site-data controls if you want to reset the demo profile.

## Scope

All schemes and eligibility results are representative demo content, not authoritative application advice. A production version should fetch verified, current programme rules from official government sources and add secure authentication, consent, and backend validation.
